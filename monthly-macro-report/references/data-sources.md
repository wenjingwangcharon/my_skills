# 月度宏观报告数据源参考

## 核心宏观经济数据

### 增长与通胀
- 搜索关键词：`中国 GDP增速 CPI PPI 最新数据` + 季度/月份
- 搜索关键词：`中国 经济运行情况 国家统计局` + 月份
- 注意：CPI/PPI 通常次月中旬发布，GDP 季度发布

### 景气指数（PMI）
- 搜索关键词：`中国 PMI 制造业 非制造业 最新`

## 搜索策略说明

1. 所有搜索使用 `topic: "finance"` 参数
2. 日期格式用实际年月，如 `2026年5月`
3. 优先搜索"国家统计局"、"央行"等官方来源的数据
4. 同一指标若不同来源数据冲突，以官方发布为准
5. 注意区分"初值"和"修正值"，优先使用修正值
6. 月度报告注重趋势和边际变化，而非单月绝对值
7. 数据未发布时标注"待发布"，并说明预计发布时间
8. 关注"超预期"/"不及预期"的市场反应，这比数据本身更重要
