# monthly-macro-report

## When to use

- 用户明确要求进行月度宏观经济分析（"帮我做一下月度宏观报告"、"分析一下当前宏观经济"、"整理一下这月经济数据"）
- 每月定时自动化触发（建议设置在每月第一个工作日 8:00）
- 用户询问"现在经济怎么样"、"当前利好哪些板块"、"经济周期在什么位置"等

## Steps

### 第一步：确定报告月份

用 Bash 工具执行 `date +%Y-%m` 获取当前年月，确定报告覆盖的数据区间（上月及更早的已公布数据）。用 `date +%Y-%m-%d` 获取具体日期。

### 第二步：搜集核心宏观经济数据

使用 WebSearch 工具，`topic: "finance"`，依次搜索以下维度（可并行 3-4 组搜索）：

**2.1 增长与通胀**
1. 搜索 `中国 {上季度} GDP增速 {上月} CPI PPI 最新数据`，提取：
   - GDP 当季同比、累计同比
   - CPI 同比、环比
   - PPI 同比

**2.2 景气指数**
2. 搜索 `中国 PMI 制造业 非制造业 {上月} 最新`，提取：
   - 制造业 PMI（及分项：新订单、新出口订单、原材料库存、从业人员）
   - 非制造业 PMI（建筑业、服务业）

**2.3 金融数据**
3. 搜索 `中国 社融 新增人民币贷款 M2 {上月} 数据`，提取：
   - 社会融资规模增量、存量同比
   - 新增人民币贷款（分居民/企业）
   - M2 同比增速

**2.4 实体经济**
4. 搜索 `中国 工业增加值 固定资产投资 社会消费品零售 {上月}`，提取：
   - 规模以上工业增加值同比
   - 固定资产投资累计同比
   - 社会消费品零售总额同比

> 搜索时注意数据发布时滞：CPI/PPI 通常次月中旬发布，PMI 月末/次月初，社融 次月中旬，GDP 季度发布。若当月数据尚未发布，使用最近一期已公布数据并标注日期。

### 第三步：搜集货币与财政政策动向

搜索 3-4 次不同关键词：

1. `中国 降息降准 LPR MLF {当月} 货币政策 最新` — 提取近期利率调整、公开市场操作、政策信号
2. `中国 专项债 财政政策 减税 {当月} 积极` — 提取专项债发行进度、财政支出力度、减税降费措施
3. `央行 货币政策执行报告 {近期季度}` — 提取央行对经济判断和政策基调
4. `国务院 常务会议 经济政策 {当月}` — 提取国常会最新政策部署

从搜索结果中梳理出：
- **货币政策基调**：宽松 / 中性偏松 / 中性 / 中性偏紧 / 紧缩
- **财政政策基调**：积极 / 中性 / 收缩
- **近期关键政策动作**：3-5 条

### 第四步：搜集重点产业政策方向

搜索 2-3 次：

1. `中国 AI 半导体 新能源 产业政策 {当月}` — 提取科技/新能源领域最新政策
2. `中国 房地产政策 消费刺激 {当月}` — 提取地产和消费领域政策
3. `中国 出口支持 外贸政策 {当月}` — 提取外贸领域政策

梳理出当前政策**重点扶持**和**调控抑制**的行业方向。

### 第五步：搜集全球经济与外部环境

搜索 2-3 次：

1. `美联储 利率 {当月} 降息预期 美国经济` — 提取美联储利率政策、经济前景
2. `中美贸易 关税 {当月} 最新进展` — 提取中美贸易关系动态
3. `中国 出口 进口 {上月} 外贸数据` — 提取进出口增速、贸易伙伴结构

### 第六步：搜集补充数据（可选）

若前面数据不足以支撑分析，额外搜索：

1. `中国 就业 失业率 {上月}` — 城镇调查失业率
2. `中国 房地产 销售 新开工 {上月}` — 地产销售面积/金额、新开工面积
3. `A股 北向资金 {上月} 净流入` — 外资流向
4. `LPR 利率 {当月}` — 最新贷款市场报价利率

### 第七步：经济周期定位与逻辑推导

基于以上数据，进行综合判断：

1. **经济周期定位**：参考美林时钟框架，判断当前处于四阶段中的哪一段：
   - 复苏期（GDP↑ 通胀↓）→ 股票最优
   - 过热期（GDP↑ 通胀↑）→ 商品最优
   - 滞胀期（GDP↓ 通胀↑）→ 现金最优
   - 衰退期（GDP↓ 通胀↓）→ 债券最优

2. **关键矛盾识别**：用"X强Y弱"框架提炼当前经济核心矛盾（如"生产强需求弱"、"外需强内需弱"等）

3. **政策-经济互动判断**：政策力度能否对冲经济自发下行？力度是加码还是减弱？

4. **利好板块推导逻辑**：
   - 政策重点扶持 → 直接受益板块
   - 经济数据超预期 → 景气上行板块
   - 外部环境变化 → 出口链/避险资产

### 第八步：板块利好排序

将利好板块分为三个梯队：

**第一梯队（强利好）**：政策最优先 + 景气数据验证 + 外部催化
**第二梯队（中利好）**：政策支持 + 景气边际改善
**第三梯队（弱利好/结构性）**：政策间接受益 / 细分领域景气

**回避板块**：政策抑制 / 景气下行 / 估值过高

每个板块需给出 2-3 句话的核心逻辑说明。

### 第九步：整理报告

1. 读取 `@templates/report.md` 模板
2. 将数据和分析填入模板对应位置
3. 报告结构包括：
   - 核心宏观经济数据总览（表格）
   - 货币与财政政策综述
   - 产业政策方向
   - 全球环境与外部因素
   - 经济周期定位与关键矛盾
   - 利好板块排序（含逻辑说明）
   - 回避板块（含逻辑说明）
   - 下月关键变量与观察信号
4. 读取 `@references/analysis-framework.md` 确保分析框架完整

### 第十步：保存报告

将报告保存到用户工作目录下：`{workspace}/宏观经济分析/{年月}-宏观经济分析报告.md`

若目录不存在，先创建。

## Pitfalls

- **数据发布时滞**：不同指标的发布时间不同，搜索时注意是否已公布。未公布的数据标注"待发布"而非留空，并说明预计发布时间
- **同比 vs 环比**：注意区分同比和环比数据，PMI 是环比概念（50 以上为扩张），CPI/PPI 同比和环比方向可能不一致
- **基数效应**：同比数据受去年基数影响较大，需结合两年平均增速或环比分析
- **数据修正**：初值与终值可能不同（尤其 GDP），优先使用最新修正值
- **政策表述变化**：央行货币政策报告中的措辞变化（如"合理充裕"→"充裕"）往往比具体操作更有信号意义，需仔细对比
- **中美数据时差**：美国非农/CPI 等数据发布在北京时间晚间，可能不在当日搜索结果中，需额外关注
- **季节性因素**：1-2 月数据受春节扰动大（工业、出口等），3 月合并看或用 1-2 月累计同比
- **利好/利空的主观性**：板块排序是概率判断而非确定性结论，报告必须注明"以上分析基于当前可得数据，不构成投资建议"

## Verification

- 报告中每个核心指标都有具体数值和发布日期，无空白字段
- 经济周期定位与数据方向一致（如 GDP 下行 + CPI 下行，不应定位为"过热期"）
- 利好板块逻辑与数据/政策一一对应（不能出现"数据不支持但标注强利好"的情况）
- 回避板块有明确的利空逻辑（而非笼统说"不看好"）
- 下月关键变量至少列出 3 个可观测信号
- 报告末尾包含免责声明
- 报告已保存到文件系统
