# table-to-chart

把用户提供的数据表渲染成图表。用户对图表的视觉、标注、协作节奏有一套固定且明确的偏好，本 skill 是这套偏好的权威记录。默认用 `show_widget`（先 `read_me(["chart"])`）内联渲染 SVG/HTML。

## When to use
- 用户贴出数据表（截图或文本）并要求"用图展示 / 画个图 / 用什么图更直观 / 这个也用图体现"。
- 已有图表要求调整（改配色、改柱高口径、去注释、改标注格式、加日期、去重叠等）。
- 只要是"为该用户根据表格作图"，无论新画还是微调，都先加载本 skill。

## Steps
1. 先 `read_me(["chart"])` 加载图表模块，遵守当前 IDE 主题（light 用深色文字、深色背景禁用）。
2. **选图型**：先判断表的核心信息再选，不要默认柱状图。
   - 多指标但量级差极大（如文件百万级 vs 知识号百级）→「100% 占比条」或「前值统一基准 + 后值按增幅往右延伸」，绝不硬堆一根绝对值轴。
   - 分布/不平等（人 vs 券错位）→ 背靠背对称条形（首选）或洛伦兹曲线。
   - 转化链路 → 漏斗图。
   - 前后对比 → 分组条形，右侧放大环比增幅。
   - 趋势 → 折线图，配活动节点竖虚线。
3. **配色固定 Excel 三色**：蓝 `#4472C4`、橙 `#ED7D31`、灰 `#A5A5A5`。全报告统一，不换色系。
4. **柱高/条长语义必须名副其实**：说"按人数"就用绝对人数当高度，占比只作标注文字；反之亦然。绝不偷偷拿占比当柱高。
5. **标注格式**：`894人(55.84%)`、`5615张(33.05%)`——绝对数在前、占比括号在后。关键比率/增幅放大加粗突出（大字），是看图第一落点。
6. **克制注释**：默认只留标题 + 图例 + 图形本体。副标题、底部"XX基准"小字、冗余结论行一律不加（用户反复要求删）。**但合计总值要保留**，放标题下方（如"日均总覆盖 187 人"，蓝色加粗）。
7. **顺序默认跟原表**，不主动按大小重排（除非用户明确要求）。
8. **活动节点用竖虚线标注**（如 6/8、6/18），图例里补日期区间（活动前 5.10–6.7 / 活动后 6.8–7.6）。
9. 渲染后简述 2-3 个从图上能看出的关键结论，最后可问是否导出 PNG 或嵌入 docx。

## Pie / Doughnut Charts — 纯 SVG 渲染（严禁 CDN）

**饼图和环形图必须用纯 SVG 渲染**，禁止使用 Chart.js 或任何 CDN 异步加载的图表库。

原因：`show_widget` 中 Chart.js CDN 脚本异步加载，初始化代码常在 CDN 未就绪时执行，导致 canvas 留白（已多次验证不可靠）。

正确做法：
- 用 Python 预计算 SVG `<path>` 的 doughnut/slice 弧线（`M{x1o} {y1o} A{R} {R} 0 {la} 1 {x2o} {y2o} L{x2i} {y2i} A{r} {r} 0 {la} 0 {x1i} {y1i} Z`）
- 所有颜色、数值、标注都硬编码在 SVG 中，零外部依赖

**布局硬约束**（已踩坑——右侧文字被 viewBox 切掉）：
- `viewBox` 强制 `"0 0 680 H"`（Visualizer 工具硬约束，不能突破，否则拒绝渲染）
- 饼图 `cx=160 cy=230 R=120 r=65`（**不要**写 cx=190 r=145，会让右侧图例无空间）
- 图例 `rect swatch x=305`、活动名 `text x=325`、数值 `text x=665 text-anchor=end`
- 字体 `font-size=12`，行高 30px
- 渲染前必须校验：**最长图例文本**（如 "下载双端领算力 116.51万(1.35%)" 约 18 字符）从 x=325 排到 x=665（340px 空间）能装下。如果更长 → 把饼图缩到 R=100，或字号降到 11
- `H` 视图例行数：3 行→320，4 行→360，5 行→380~400
- "其他" 行灰字 `fill=#999`
- **不要在饼图扇区内放数字标注**——所有数字统一在右侧图例，避免重叠

## Pitfalls
- **数据必须来自用户原表**。中间档缺数就问/等截图，绝不用占比反推臆造——用户对数据准确性要求极高。合计要对齐（如 1601 人 / 16988 张）。
- **重叠是高频毛病**：长条上顶到边的数值移入条形内部（白字左对齐）避免和轴/标签撞。
- **别重构**："不用改变形式，微调一下就行"是高频诉求。用户常贴红框截图指某一处，只改那一处，形式/配色/布局其余全部不动。
- **别自作主张加戏**：说去掉注释就只去注释，别顺手改别的。
- **忌花哨**：单一渐深或纯色，不要多余装饰线、边框、中间分隔条（曾因中间两道分隔线被质疑）。

## Verification
- 配色是否为 `#4472C4 / #ED7D31 / #A5A5A5`。
- 柱高/条长口径与用户要求一致（人数 vs 占比不能搞反）。
- 标注为"数量(占比)"格式，关键比率已放大。
- 合计总值在，冗余注释已删。
- 所有绝对数与原表逐档核对、合计对齐，无臆造。
