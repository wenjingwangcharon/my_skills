# 活动算力数据处理

将 ima 算力活动底表转换为周报 Excel，包含两个 sheet，支持每周追加。

## 触发条件

用户说"处理本周底表""追加到周报""更新周报数据"等，并提供底表 Excel 文件路径时触发。

## 输入参数

使用前必须向用户确认以下三项：

1. **底表文件路径**（source）：源数据 Excel，由灯塔 DataTalk 导出
2. **输出文件路径**（output）：目标周报 Excel；首次运行自动创建，后续运行在原文件顶部追加
3. **日期区间**（date）：格式如 `6.26-7.02`，表示上周五到本周四

## 执行方式

### 本地 Excel（含数据条和图表）

```bash
python {skill_dir}/scripts/process.py --source <底表路径> --output <输出路径> --date <日期区间>
```

### WeCom 在线表格（无数据条/图表，文本格式）

```bash
python {skill_dir}/scripts/process.py --source <底表路径> --output <本地Excel路径> --date <日期区间> --wecom
```

**企微模式**：先更新本地 Excel，再从中读取全量数据以文本形式写入企微在线表格（企微 API 不支持条件格式和图表，所以数据条和饼图仅在本地 Excel 中生效）。

## 底表结构要求

源 Excel 需包含以下列（DataTalk 导出的标准格式）：

| 列 | 字段 |
|---|---|
| sort_no | 排序号（1-10 为活动，999 为 TOTAL） |
| 活动 | 活动名称 |
| 本周下发算力 / 本周会话消耗算力 / 本周过期消耗算力 | 本周三类算力 |
| 本周下发人数 / 本周消耗人数 / 本周过期人数 | 本周三类人数 |
| 累计下发算力 / 累计会话消耗算力 / 累计过期消耗算力 | 累计三类算力 |
| 累计下发人数 / 累计会话消耗人数 / 累计过期人数 | 累计三类人数 |
| 上周下发算力 / 上周消耗算力 / 上周过期算力 | 上周三类算力 |
| 累计付费用户 | 累计付费人数 |

## 输出说明

### Sheet1：活动下发详情

每周追加一个 14 行的数据块（黄色标头 + 灰色标题 + 9 个活动行 + TOTAL 行 + 2 空行）。

| 列 | 内容 | 来源 |
|---|---|---|
| 活动 | 9 个活动名 + TOTAL | 固定顺序，排除"购买算力" |
| 本周下发/消耗/过期算力 | ≥1万显示"XX.XX万"，否则显示整数 | 底表本周数据 |
| 下发/消耗/过期占比 | raw ratio，单元格格式 0.00% | = 本活动值 / TOTAL值 |
| 环比变化 | raw ratio，单元格格式 0.00% | = (本周 - 上周) / 上周 |
| 本周下发/消耗/过期人数 | 整数 | 底表，TOTAL 行取自底表非加总 |
| 本周人均下发/消耗/过期 | 整数 | = 算力值 / 人数 |

### Sheet2：活动累计下发

每周追加一个 14 行的数据块（黄色标头 + 灰色标题 + 9 个活动行 + TOTAL 行 + 2 空行）。

| 列 | 内容 | 来源 |
|---|---|---|
| 活动 | 9 个活动名 + TOTAL | 固定顺序 |
| 累计下发/消耗/过期算力 | ≥1万显示"XX.XX万" | 底表累计数据 |
| 下发占比 | raw ratio，单元格格式 0.00% | = 本活动累计 / TOTAL累计 |
| 消耗率 | raw ratio，单元格格式 0.00% | = 累计消耗 / 累计下发 |
| 过期率 | raw ratio，单元格格式 0.00% | = 累计过期 / 累计下发 |
| 余额 | ≥1万显示"XX.XX万" | = 累计下发 - 累计消耗 - 累计过期 |
| 余额率 | raw ratio，单元格格式 0.00% | = 余额 / 累计下发 |
| 付费率 | raw ratio，单元格格式 0.00% | = 累计付费 / 累计下发人数 |

## 追加逻辑

- 如果输出文件已存在：在 Sheet1 和 Sheet2 的第 1 行之前各插入 14 行，写入本周数据
- 新旧数据之间自动保留 2 行空白间隔
- 旧数据的格式和内容完全保留

## 可视化增强（仅本地 Excel）

每次运行自动为 Sheet1 最新周数据块追加以下可视化元素：

### 数据条（环比列）

- **位置**：Sheet1 列 D（下发环比，col 4）、列 I（消耗环比，col 9）、列 N（过期环比，col 14）
- **范围**：新数据块的 10 行（9 活动 + TOTAL），即 rows 3-12
- **样式**：实色（`gradient="0"`），蓝色 `#4472C4`，数值范围 `[-1, 1]`
- **数值**：环比列从格式化文本覆写为 raw float + `0.00%` 数字格式，数据条直接基于数值绘制
- **旧块**：旧周的环比数据保持为格式化文本，不带数据条（仅最新一周生效）

### 饼图（本周算力分布）

- **位置**：独立 Sheet「图表」
- **数据源**：隐藏 Sheet「图表数据」→ 最新周 TOTAL 行的三类算力原始数值
- **配色**：Excel 三色（蓝 `#4472C4` / 橙 `#ED7D31` / 灰 `#A5A5A5`）
- **标签**：类别名 + 百分比
- **每次覆盖**：新周运行后图表替换为当前周数据，不保留历史图表

- 黄色填充（#FFFF00）：本周数据标头行（A、B 列）
- 灰色填充（#D9D9D9）+ 加粗：列标题行、TOTAL 行
- 百分比列使用 Excel 数字格式 `0.00%`（存储 raw ratio）
- 分母为 0 的比率单元格留空
