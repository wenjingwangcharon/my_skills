# 网站设计规范（design）

`run_today.py` 生成的日报网页是一个**自包含、零依赖、纯前端**的静态 HTML（单文件 `site/index.html`，
内联 CSS + 原生 JS，无外部框架、无 CDN）。本文件是风格的「规范」，实现全部在
`scripts/build_daily_html.py`——改样式只动那个文件。

设计目标：**干净、轻量、可每天自动重渲染而视觉恒定**。每天变化的是中间卡片的数量和内容，
头部（标题 / 日期 / 元信息 chips）、「今日趋势」摘要区、导航栏、底部（今日小结 / footer）结构永远一致。

| 语义 | 变量 / 值 | 用途 |
|------|-----------|------|
| 页面背景 | `--bg:#f5f6f8` | body 背景 |
| 卡片背景 | `--card:#fff` | 卡片 / 趋势区 / 小结区底 |

## 3. 关键组件

- **header**：`h1` 30px；副标题 14px muted；`meta-chip` 浅灰胶囊（背景 `#eef1f6`）。
- **今日趋势区**：白底圆角卡片，`h2` 用主题蓝；`<p>` 14px、行高 1.7。
- **nav 吸顶**：`position:sticky; top:0`；背景 `rgba(245,246,248,.92)` + `backdrop-filter:blur(10px)`；
  底部 1px 边框。内含：信源 pill（激活态填充主题蓝、白字）、「★ 只看高重要性」切换 pill（激活态红）、
  搜索框（width 180px）、排序 `<select>`。
- **article 卡片**：白底、1px 边框、14px 圆角、左侧 4px 信源色竖条（`::before`）；hover 上浮 2px + 阴影。
  结构：信源徽标（彩色小标）+ 重要性圆点；标题（16.5px，链接默认继承文字色，hover 变蓝+下划线）；
  来源·分类（12.5px muted）；摘要（14px）；目录（有序列表，13px）。
- **今日小结区**：渐变背景 `linear-gradient(135deg,#eef3ff,#f6f0ff)` + 淡蓝边框，圆角 16px。
- **响应式**：`max-width:760px` 时 `.grid` 单列、搜索框收窄到 130px。

---

## 4. 交互（纯前端 JS，无需后端）

- **信源筛选**：点击 pill 仅显示该信源卡片（data-src 过滤）。
- **高重要性切换**：点击后仅显示 `data-imp >= 4` 的卡片。
- **搜索**：输入即按标题（小写）实时过滤。
- **排序**：序号 / 重要性降序 / 信源顺序。
- **整卡跳转**：点击卡片空白处（非链接文字）在新标签页打开原文 `data-url`；点标题链接同样打开原文。
- 所有卡片数据通过 `data-*` 属性驱动，JS 在 DOM 加载后 `apply()` 一次完成初次渲染。

---

## 5. 如何改动风格

1. 调色：改 `build_daily_html.py` 顶部 `:root` 变量或 `SRC_COLOR` / `IMP_COLOR` 字典。
2. 布局：改 `<style>` 内 `.grid`（列数）、`.card`（圆角/间距）、`.nav`（吸顶行为）。
3. 交互：改 `<script>` 内 `apply()` 与监听器。
4. 改完跑一次 `run_today.py`（或单独 `python build_daily_html.py`）即可看到新网页，
   不影响抓取与 markdown 层——**风格与数据是解耦的**。
