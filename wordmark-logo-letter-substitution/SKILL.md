# Wordmark Logo 字母替换

## 概述

当品牌名称已经确定，用户希望 logo 更有辨识度或传达功能时，把特定字母替换成图标是常见做法。本技能指导如何在 Ardot 画布上快速搭建这种字标，并保持可读性与缩放一致性。

## 触发场景

- 用户要求基于某个名字做字标 / wordmark / logo。
- 用户明确提出把某个字母变成某种图形（笑脸、对勾、星星、叶子等）。
- 最终 logo 需要兼顾小尺寸、单色应用（印刷、反白、 favicon）。

## 工作流

1. **确认要替换的字母和含义**
   - 询问或从需求中提炼：哪个字母被替换、替换后的图形象征什么。
   - 建议只替换 1–2 个字母，过多会破坏可读性。

2. **为未替换字母选择基础字体**
   - 可爱/亲切风格：拉丁字母用 Poppins Bold / SemiBold，中文用 Noto Sans SC Medium / Bold。
   - 极简/科技风格：可用更几何的字体（如 Outfit、Inter）。

3. **把词拆成三段横向排列**
   - 左侧：第一个被替换字母的自定义 SVG 图形。
   - 中间：剩余普通字母组成的文本节点。
   - 右侧：末尾被替换字母的自定义 SVG 图形（如果有）。
   - 三者放入一个水平 auto-layout 框架，gap 2–6 px，垂直对齐 CENTER。

4. **绘制自定义 SVG 字形**
   - SVG 框架高度应与中间文字的字高（x-height 或 cap-height）对齐，视觉高度约为字号的 70–80%。
   - 笔画粗细和颜色与中间文字保持一致，确保整体锁扣感。
   - 可爱风格可加入腮红、圆角端点等细节，但不要过度装饰。
   - 替换后的图形仍应能识别为原字母，不能变形到失去字母属性。

5. **组装主方案**
   - 背景：浅色奶油底或中性色。
   - 字身：深靛蓝或品牌主色。
   - 功能强调：用单一粉彩色（如粉红）突出图标含义（如对勾）。
   - 添加标题和说明文字，解释替换逻辑。

6. **输出单色版本**
   - 复制一份字标，将所有笔画改为与字身同色。
   - 验证 logo 在单一场景（印刷、压凹、反白）仍成立。

7. **截图验证**
   - 截取整页，重点检查：
     - 自定义图形是否与中间文字的 x-height 对齐。
     - 图形与文字之间的间距是否均匀。
     - 替换后的字母是否仍可辨识。
   - 如发现错位，调整 SVG 的 viewBox 中心或框架高度，直到视觉上融为一体。

## 示例

- 词：`offerbuddy`
- 替换：首字母 `o` → 笑脸；尾字母 `y` → 对勾。
- 中间文字：`fferbudd`
- 组合效果：`☺fferbudd✓`

## 注意事项

- 在 Ardot 中，`frame` 传入的 `svg` 属性保存后会被解析为原生的 `ELLIPSE` / `VECTOR` 等子节点。若后续需要局部调整（如只放大腮红、改眼睛颜色），应先用 `batch_read` 读取该 frame 的 children，定位到具体子节点，再用 `U()` 更新其几何属性（`x`、`y`、`width`、`height`、`fills`、`strokes`），而不是直接更新 `svg`。
- 品牌名过长时，建议只把替换图形作为点缀，而非完全替代字母。
- 设计完成后要在心里做小尺寸测试：图标缩到 favicon 大小时是否还清晰，若不行就简化。
- 主字标尽量不用渐变和阴影，它们适合 app icon 变体，但不利于真正的 logo 应用。
