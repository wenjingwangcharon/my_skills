# 晨间信息扫描数据源参考

## 外盘指数
- 搜索关键词：`美股收盘 道琼斯 纳斯达克 标普500` + 当日日期
- 搜索关键词：`欧洲股市收盘 DAX 富时 CAC`
- 搜索关键词：`日经225 收盘`

## A50期货
- 搜索关键词：`富时中国A50期货 夜盘 收盘`
- A50期货交易时间：北京时间 9:00-16:30, 17:00-次日4:44

## 商品价格
- 搜索关键词：`国际油价 收盘 WTI 布伦特`
- 搜索关键词：`黄金收盘 COMEX`
- 搜索关键词：`LME铜 收盘`
- 搜索关键词：`铁矿石 价格`

## 汇率与利率
- 搜索关键词：`美元指数 收盘`
- 搜索关键词：`人民币汇率 中间价`（中间价通常早晨9:15公布）
- 搜索关键词：`美国十年期国债收益率`

## 国内要闻
- 搜索关键词：`A股 隔夜要闻 早报` + 当日日期
- 搜索关键词：`央行 公开市场操作` + 当日日期
- 搜索关键词：`国务院 政策 最新`
- 搜索关键词：`证监会 交易所 公告 最新`

## 重要公告
- 搜索关键词：`A股 重要公告` + 当日日期
- 搜索关键词：`上市公司 公告 增持 减持 业绩`
- 搜索关键词：`IPO 申购 上市` + 当日日期

## 经济日历
- 搜索关键词：`财经日历` + 当日日期
- 搜索关键词：`经济数据发布` + 当日日期
- 常见重要数据：CPI、PPI、PMI、社融、M2、进出口、GDP

## 搜索策略说明
1. 优先使用 `topic: "finance"` 参数搜索金融相关信息
2. 日期格式用当天实际日期，如 `2026年5月27日`
3. 每个维度搜索后，从结果中提取具体数值，填入报告模板
4. 若某数据搜索不到，标注"暂未获取"而非留空
5. 国内要闻部分，搜索 2-3 次不同关键词以覆盖不同来源
