# Emblem Logo 设计

## 概述

Emblem logo 是一种以图形符号为核心的品牌标识，常用于 favicon、App 图标或字标旁的辅助徽章。本技能帮助用户从业务功能中提炼一个核心隐喻，设计成线条干净、可单色、可缩放的 emblem。

## 触发场景

- 用户需要一个独立图标（favicon、App icon、辅助徽章）来配合字标。
- 用户要求 logo「简洁明了」并能体现产品功能。
- 用户希望 logo 在单色、小尺寸下仍成立。

## 工作流

1. **提炼一个核心隐喻（1 个就够）**
   - 从产品的「最终价值」或「高频动作」中找符号：
     - 拿到 offer → 信封、对勾、印章
     - 日程管理 → 日历、时钟、清单
     - 通过 / 完成 → 对勾、环形徽章
   - 避免同时使用多个不相关的隐喻；一个主导符号 + 一个辅助符号（如对勾）足够。

2. **选择 emblem 风格**
   - 可爱/友好：圆角、线条较粗、单一粉彩色作为功能强调。
   - 极简/科技：细等线、几何图形、单色或双色。
   - 手绘：不规则描边、略带抖动。手绘风格更建议用于字标，emblem 小尺寸会糊掉，慎用。

3. **一次出 2–3 个候选方向**
   - 每个候选用同一个风格、同一个品牌色，只改变核心隐喻。
   - 例如：信封+对勾、日历+对勾、环形 O+对勾。
   - 放在同一张画布上横向对比，标题统一标注含义。

4. **用 SVG 框架绘制 emblem**
   - 使用 `type: "frame"` + `layout: "none"` + `svg` 属性。
   - viewBox 建议 0 0 120 120 或 0 0 200 200，保持源文件清晰。
   - 主线条使用品牌深色（如靛蓝），功能强调使用品牌辅助色（如粉红）。
   - 使用 `stroke-linecap="round"` 和 `stroke-linejoin="round"` 让线条更友好。

5. **做单色 / 小尺寸测试**
   - 在同页底部增加一行「favicon 测试」：把 emblem 缩小到 36–40 px，并用单色绘制。
   - 检查要点：
     - 图形轮廓在 40px 下仍完整。
     - 内部细节（如小圆点、细线）不会糊成一片。
     - 对勾、十字、环形等关键符号在单色下依然清晰。

6. **截图验证并收敛**
   - 整页截图，检查：
     - 三个候选大小、粗细一致。
     - 小尺寸测试没有明显变形或丢失。
     - 没有某个候选和另外两个风格不一致。
   - 如某个候选小尺寸糊掉，直接放弃或简化到只剩轮廓。

## 示例

为「帮助秋招」的 offerbuddy 设计 emblem：
- 候选 1：信封 + 对勾（象征拿到 offer）。
- 候选 2：日历 + 对勾（象征面试日程与待办完成）。
- 候选 3：环形 O + 对勾（品牌首字母 O 的抽象徽章）。
- 小尺寸测试：三个候选均用单色重绘为 40px，验证 favicon 可读性。

## 注意事项

- 初稿不要加渐变、阴影、纹理；这些适合后期的 app icon 变体，不是 logo 主稿。
- 如果用户没有明确选择，把三个候选并排呈现，并说明你的倾向与理由。
- Emblem 和字标最终应能组合成 logo 系统：字标放在 header、emblem 放在 favicon / 启动图标。
