# 投资追踪表格模板

> 基于"了解一个国家的七层分析框架"构建
> 使用说明：每次更新时，在"最新数值"栏填入新数据，在"变化趋势"栏标注 ↑↓→，并更新"上次更新"日期

---

## 使用指南

### 文件维护方式
- **复制本模板**保存为 `investment_tracker.md`，放在你的投资研究目录
- 每次更新时，**只更新"最新数值"和"上次更新"两列**
- "变化趋势"由你手动判断填写（↑上升 ↓下降 →持平 ↗缓升 ↘缓降）
- 建议**每季度**做一次完整更新

### 更新优先级
| 优先级 | 层次 | 原因 |
|--------|------|------|
| 🔴 高 | ⑤ 经济体系 | 投资最直接相关的数据，建议每季度更新 |
| 🔴 高 | ⑦ 对外关系 | 地缘政治变化快，对跨境投资影响直接，建议每月关注 |
| 🟡 中 | ② 人口社会 | 年度数据，每年更新一次即可 |
| 🟡 中 | ⑥ 社会民生 | 年度数据，每年更新一次 |
| 🟢 低 | ① 地理禀赋 | 几乎不变，每3-5年更新一次 |
| 🟢 低 | ③ 历史基因 | 不变，无需定期更新 |
| 🟢 低 | ④ 政治体制 | 重大事件触发更新 |
