## 更新流程

### 完整流程（功能四）

```
步骤1：判断哪些报告需要更新
  → 参考各层次更新频率
  → 第一层（3年）、第二层（1年）、第三层（5年）、第四层（事件触发）
  → 第五层（3个月）、第六层（1年）、第七层（1个月）

步骤2：搜索最新数据，更新本地 .md 文件
  → 对每个需要更新的报告，搜索对应层次的最新数据
  → 更新报告中的关键数字和"上次更新"日期
  → 在报告末尾的"版本记录"中追加本次更新说明

步骤3：上传更新后的文件到 IMA
  → 使用 ima-skill 的 knowledge-base 上传流程
  → check_repeated_names → create_media → cos-upload → add_knowledge
  → 如触发重名：建议用户选择"保留两者（加时间戳）"

步骤4：验证上传结果
  → 调用 get_knowledge_list 确认文件已上传
  → 向用户报告上传结果
```

## IMA 上传注意事项

1. **不支持替换**：IMA API 不支持替换已有文件，只能上传新文件
2. **重名处理**：`check_repeated_names` 会在发现重名时询问用户：
   - 保留两者（文件名加时间戳后缀）
   - 取消本次上传
3. **建议策略**：每次更新后上传新版本，文件名保持不变，让 IMA 触发重名检查，用户选择是否保留旧版
4. **手动清理**：如知识库中旧版本过多，需用户手动登录 ima.qq.com 删除

## 报告版本记录格式

每次更新报告后，在报告末尾追加：

```markdown
## 版本记录

| 日期 | 更新内容 | 数据来源 |
|------|---------|---------|
| 2026-07-05 | 首次创建 | 国家统计局2025年统计公报、CIA Factbook等 |
| 2026-10-15 | 更新第五层经济数据（Q3 GDP、最新PMI等） | 国家统计局2026年季度数据 |
```

## 各报告更新检查清单

### 第一层：地理禀赋（每3年）
- [ ] 耕地面积（自然资源部年度国土变更调查）
- [ ] 森林覆盖率（国家林草局）
- [ ] 稀土/矿产资源储量（USGS最新报告）
- [ ] 水资源数据（水利部年度水资源公报）

### 第二层：人口社会（每年，2-3月）
- [ ] 总人口（国家统计局年度统计公报）
- [ ] 出生率/死亡率/自然增长率
- [ ] 年龄结构（人口普查或抽样调查数据）
- [ ] 城镇化率
- [ ] 流动人口规模

### 第三层：历史基因（不需定期，仅重大解读变化时）
- 通常不需要更新数据，但如有权威新史料或解读变化可追加

### 第四层：政治体制（重大事件触发）
- [ ] 党代会/中央全会后：更新政治局、中央委员名单
- [ ] 国务院机构改革后：更新机构设置
- [ ] 重要法律法规通过后：更新相关描述

### 第五层：经济体系（每季度，核心层）
- [ ] GDP总量与增速（季度后15-20日）
- [ ] CPI/PPI（每月9-10日）
- [ ] 制造业/非制造业PMI（每月最后一天）
- [ ] 社会消费品零售总额（每月15日）
- [ ] 固定资产投资（每月15日）
- [ ] 工业增加值（每月15日）
- [ ] 进出口数据（每月13-14日）
- [ ] M2与社融规模（每月10-15日）
- [ ] 财政收入与支出（每月15-20日）
- [ ] 70城房价指数（每月15-16日）

### 第六层：社会民生（每年）
- [ ] 教育数据（教育部年度统计公报，每年6月）
- [ ] 医保/社保覆盖人数（国家医保局/人社部，每年5-6月）
- [ ] 居民收入与消费（国家统计局，每年2-3月）
- [ ] 空气质量（生态环境部，每年6月）

### 第七层：对外关系（每月关注）
- [ ] 中美关系最新动态
- [ ] 一带一路新签协议/投资项目
- [ ] 金砖/上合最新成员变动
- [ ] 中国对外投资最新数据（商务部，每年9-10月）
- [ ] 人民币汇率与国际化进展
