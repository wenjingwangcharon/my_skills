# 投资追踪数据来源与更新操作指南

本文件提供每个指标的具体获取方法和更新操作步骤。

---

## 通用更新流程

每次更新建议按以下步骤操作：

1. **确定本次更新的范围**（哪些层次、哪些指标）
2. **访问对应数据来源**（见下文各节）
3. **记录最新数值和日期**
4. **在追踪表中填写"变化趋势"**（↑↓→）
5. **在"综合研判记录"中写下本季度判断**

## 第一层：地理禀赋

> 更新频率：每3-5年一次，或重大资源勘探新闻发布时

| 指标 | 获取方法 | 官方来源 |
|------|---------|---------|
| 国土面积 | 搜索"中国 国土面积 202X" | 中国政府网 / 自然资源部 |
| 耕地面积 | 关注"全国国土变更调查"年度公告 | 自然资源部 www.mnr.gov.cn |
| 森林覆盖率 | 关注"中国森林资源报告" | 国家林草局 www.forestry.gov.cn |
| 稀土储量 | 搜索"稀土储量 全球占比" | USGS Mineral Commodity Summaries |
| 石油进口依存度 | 计算：原油进口量 / 原油消费量 | 海关总署 + 国家统计局 |
| 水资源总量 | 搜索"中国水资源公报 202X" | 水利部 www.mwr.gov.cn |

**操作提示**：本层数据变化极慢，建议仅在看到相关新闻时（如"中国在XX发现特大油田"）才更新。

## 第二层：人口与社会结构

> 更新频率：每年1-2月关注国家统计局年度数据公告

| 指标 | 获取方法 | 官方来源 | 发布时间 |
|------|---------|---------|---------|
| 总人口 | 国家统计局年度统计公报 | stats.gov.cn | 每年2-3月 |
| 总和生育率 | 国家卫健委妇幼健康司报告 | nhc.gov.cn | 不定期 |
| 年龄结构 | 国家统计局"人口抽样调查" | stats.gov.cn | 每年4月 |
| 城镇化率 | 国家统计局年度数据 | stats.gov.cn | 每年2-3月 |
| 流动人口 | 国家统计局"流动人口发展报告" | stats.gov.cn | 每年 |
| 结婚登记数 | 民政部"社会服务发展统计公报" | mca.gov.cn | 每年6月 |

**关键网址**：
- 国家统计局数据发布日历：stats.gov.cn/sj/zxfb/
- 年度统计公报：stats.gov.cn/sj/tjgb/ndtjgb/
- 人口抽样调查：stats.gov.cn/sj/pcsj/rkpc/

**操作提示**：最方便的方式是关注"国家统计局"微信公众号，每次数据发布会有推送。

## 第五层：经济体系（核心，更新最频繁）

### A. 月度数据（每月中旬更新上月数据）

| 指标 | 获取方法 | 官方来源 | 发布时间 |
|------|---------|---------|---------|

| CPI/PPI | 国家统计局 > 价格数据 | stats.gov.cn | 每月9-10日 |
| 社会消费品零售总额 | 国家统计局 > 工业/投资/消费 | stats.gov.cn | 每月15日 |
| 固定资产投资 | 同上 | stats.gov.cn | 每月15日 |
| 工业增加值 | 同上 | stats.gov.cn | 每月15日 |
| 进出口数据 | 海关总署官网 > 统计数据 | customs.gov.cn | 每月13-14日 |
| 新增信贷/社融 | 央行 > 统计数据 > 货币供应量 | pbc.gov.cn | 每月10-15日 |
| 70城房价 | 国家统计局 > 房价数据 | stats.gov.cn | 每月15-16日 |

## 数据质量与交叉验证

### 为什么要交叉验证？

同一指标在不同来源可能会有差异，原因包括：
- 统计口径不同（如GDP有生产法、支出法两种核算方式）
- 数据修订（国家统计局会回溯修订历史数据）
- 季节性调整方法不同

### 推荐交叉验证组合

| 指标 | 主要来源 | 验证来源 |
|------|---------|---------|
| GDP增速 | 国家统计局 | 财政部（财政收支增速参考） |
| CPI | 国家统计局 | 商务部（食用农产品价格） |
| 进出口 | 海关总署 | 各国海关数据对比 |
| 金融数据 | 央行 | Wind/同花顺终端数据 |
| 就业数据 | 国家统计局 | 人社部、智联招聘就业报告 |

## 常见问题

**Q：追踪表太多数据要填，从哪里开始？**
A：建议先填第五层（经济体系）的核心指标——GDP增速、CPI、PMI、社融、进出口。这5个指标就能覆盖大部分宏观判断需要。

**Q：我没有时间每月更新，怎么办？**
A：设置"最低维护方案"——每季度更新一次第五层核心指标，每年更新一次第二层和第六层。第一层、第三层、第四层几乎不需要动。

**Q：数据来源网址打不开怎么办？**
A：中国政府部门网站有时会改版。建议用搜索引擎搜索"指标名称 + 发布机构"（如"GDP增速 国家统计局"），通常第一条就是。

**Q：有些数据找不到最新值怎么办？**
A：在追踪表中填写"待更新"，并记录尝试获取的日期。部分数据（如基尼系数）国家统计局已多年未正式发布，可用世界银行或学术研究估算值替代，并注明来源。
