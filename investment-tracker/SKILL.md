# 投资追踪技能

## 概述

本技能帮助用户建立并维护一套基于"七层国家分析框架"的投资研究追踪体系。将宏观研究从一次性报告转化为可持续更新的工作台，指导用户高效获取关键数据、判断更新优先级、并系统化记录投资研判。

## 核心功能

本技能提供三项核心功能，根据用户请求选择使用：

### 功能一：生成投资追踪表格

当用户首次建立投资研究体系，或需要重置追踪表时，使用本功能。

**操作步骤：**

1. 从 `assets/tracker_template.md` 读取完整模板
2. 根据用户需求，可选择：
   - 生成**完整版**（七层全部包含，适合专业投资者）
   - 生成**精简版**（仅包含第五层"经济体系"的核心指标，适合大多数个人投资者）
3. 将模板内容输出给用户，保存为 `investment_tracker.md`

**精简版建议保留的指标（最低维护方案）：**

| 层次 | 保留指标 | 更新频率 |
|------|---------|---------|
| 第五层：经济体系 | GDP增速、PPI、PMI、社融规模、进出口、70城房价 | 每月/每季度 |
| 第七层：对外关系 | 中美关系状态、人民币汇率压力 | 每月 |

### 功能二：检查更新状态

当用户询问"哪些数据需要更新""追踪表是否过期""检查更新"时，使用本功能。

**操作步骤：**

1. 确认用户的追踪表文件路径（默认 `investment_tracker.md`）
2. 运行 `scripts/check_updates.py` 脚本：
   ```
   python scripts/check_updates.py <追踪表路径> [--date YYYY-MM-DD]
   ```
3. 根据脚本输出，向用户报告：
   - 哪些层次的哪些指标已过期
   - 建议本次更新的优先级
   - 具体的数据获取来源（参考 `references/data_sources.md`）

**手动判断逻辑（当脚本不可用时）：**

对于每个指标，比较"上次更新"日期与当前日期：
- 第一层：超过3年 → 需要更新
- 第二层：超过1年 → 需要更新
- 第三层：超过5年 → 需要更新
- 第四层：超过6个月，或有重大政治事件 → 需要更新
- 第五层：超过3个月 → 需要更新（核心层次）
- 第六层：超过1年 → 需要更新
- 第七层：超过1个月 → 需要更新

### 功能三：指导数据更新操作

当用户需要更新具体指标，或询问"XX数据在哪里找""如何获取XX数据"时，使用本功能。

**操作步骤：**

1. 从 `references/data_sources.md` 读取对应指标的数据获取方法
2. 向用户提供：
   - 具体的数据来源网址
   - 数据发布时间（发布日程）
   - 获取步骤（导航路径）
   - 交叉验证建议
3. 如用户请求，可直接帮用户访问网页获取最新数据（使用 WebFetch 工具）

### 功能四：更新七篇报告并同步到 IMA 知识库

当用户说"更新报告""同步到 IMA""更新 IMA 中的报告""把最新数据更新到知识库"等，使用本功能。

**前置条件：**
- 七篇报告已存在于本地（默认路径：`~/.workbuddy/projects/了解中国/` 或用户指定路径）
- IMA 凭证已配置（`~/.config/ima/client_id` 和 `api_key`）
- IMA 知识库"了解中国"ID：`KjCcsK7jDePNTjYMaXzEI0T3rCE_1HsHnvm-w3bWdkc=`

**完整工作流程：**

```
步骤1：判断哪些报告需要更新
  → 读取 references/ima_sync.md 中的"各报告更新检查清单"
  → 根据各层次更新频率判断（见"各层次维护优先级"章节）
  → 向用户确认本次要更新的报告范围

步骤2：逐个报告更新数据
  → 对每个需要更新的报告：
    a. 搜索该层次的最新数据（使用 WebSearch + WebFetch）
    b. 读取本地 .md 报告文件
    c. 更新关键数字（保留原文结构，仅更新数据）
    d. 更新"上次更新"日期
    e. 在报告末尾"版本记录"中追加本次更新说明
  → 参考 references/data_sources.md 获取各指标的数据来源

步骤3：上传更新后的报告到 IMA
  → 对每个更新后的报告文件：
    a. 调用 ima-skill 的 knowledge-base 上传流程
    b. preflight-check.cjs → check_repeated_names → create_media → cos-upload → add_knowledge
    c. 知识库 ID：KjCcsK7jDePNTjYMaXzEI0T3rCE_1HsHnvm-w3bWdkc=
    d. 如 check_repeated_names 返回 is_repeated=true：
       → 询问用户：保留两者（文件名加时间戳）/ 取消上传
  → 详细上传步骤见 ima-skill 的 SKILL.md（knowledge-base 子技能）

步骤4：验证上传结果
  → 调用 get_knowledge_list 确认文件已成功上传
  → 向用户报告上传结果（成功/失败/跳过）
```

**各报告更新频率（快速参考）：**

| 报告 | 层次 | 建议更新频率 | 优先级 |
|------|------|-------------|--------|
| 中国地理禀赋报告 | 第一层 | 3年 | 🟢 低 |
| 中国人口与社会结构报告 | 第二层 | 1年（每年2-3月） | 🟡 中 |
| 中国历史与文化基因报告 | 第三层 | 不需定期 | 🟢 低 |
| 中国政治体制与权力结构报告 | 第四层 | 重大事件触发 | 🟡 中 |
| 中国经济体系与发展水平报告 | 第五层 | 3个月（每季度） | 🔴 高 |
| 中国社会民生与日常生活报告 | 第六层 | 1年 | 🟡 中 |
| 中国对外关系与国际定位报告 | 第七层 | 1个月 | 🔴 高 |

**报告文件命名规范：**

更新后的报告建议保持原名不变（触发 IMA 重名检查，让用户决定处理方式）。
如需区分版本，文件名格式：`原名_YYYYMMDD.md`（如 `中国经济体系与发展水平报告_20261015.md`）

**IMA 上传注意事项：**

1. IMA API **不支持替换已有文件**，只能上传新文件
2. 重名时会触发 `check_repeated_names` 检查，询问用户处理方式
3. 建议策略：每次更新后上传新版本，旧版本由用户手动在 [ima.qq.com](https://ima.qq.com) 删除
4. 上传成功后，建议在 `references/ima_sync.md` 中记录各文件的 media_id（方便以后管理）

**最小更新方案（推荐）：**

如用户时间有限，建议仅更新**第五层和第七层**的两篇报告（覆盖投资最核心的信息），其余报告按需更新。

## 各层次维护优先级

不是所有层次都需要同等频率更新。向用户说明以下优先级：

| 优先级 | 层次 | 更新频率 | 原因 |
|--------|------|---------|------|
| 🔴 高 | 第五层：经济体系 | 每月/每季度 | 投资最直接相关的数据 |
| 🔴 高 | 第七层：对外关系 | 每月 | 地缘政治变化快，影响跨境投资 |
| 🟡 中 | 第二层：人口社会 | 每年 | 年度数据，长期趋势重要 |
| 🟡 中 | 第六层：社会民生 | 每年 | 年度数据，影响消费趋势判断 |
| 🟢 低 | 第一层：地理禀赋 | 3-5年 | 几乎不变 |
| 🟢 低 | 第三层：历史基因 | 不需定期 | 不变，仅需理解 |
| 🟢 低 | 第四层：政治体制 | 重大事件触发 | 关注党代会、中央全会、中央经济工作会议 |

## 输出格式规范

### 生成追踪表格时

输出完整的 Markdown 表格，包含以下列：
- 指标名称
- 最新数值
- 单位
- 同比/环比（如适用）
- 变化趋势（↑↓→，首次建立时留空）
- 上次更新日期
- 数据来源
- 备注（投资含义）

### 报告更新状态时

使用以下格式输出：

```
📊 更新检查报告（检查日期：YYYY-MM-DD）

🔴 需要更新（X项）：
  【第五层：经济体系】
    - GDP增速（上次更新：YYYY-MM，已过去XX天）
    - 社会消费品零售总额（...）

  【第七层：对外关系】
    - 中美关系状态（...）

🟡 即将到期（X项）：
  ...

✅ 近期已更新（X项）：
  ...
```

### 指导数据获取时

对每个指标提供：
1. **数据来源**：机构名称 + 网址
2. **发布时间**：几月几日发布，月度/季度/年度
3. **获取路径**："访问XX网站 > 点击XX菜单 > 查找XX表格"
4. **备用来源**：如官方数据延迟，推荐哪些第三方来源

## 与七层框架的关联

本技能是"了解一个国家的七层分析框架"的**维护扩展**。七层框架用于建立认知，本技能用于保持认知的时效性。

如果用户还没有建立七层框架的认知，先建议用户完成七层研究，再使用本技能建立追踪体系。

## 资源文件说明

本技能包含以下资源文件：

| 文件 | 类型 | 用途 |
|------|------|------|
| `assets/tracker_template.md` | 模板 | 完整的七层投资追踪表格模板，包含所有指标、数据来源和备注 |
| `references/data_sources.md` | 参考 | 每个指标的具体获取方法、官方来源网址、发布时间表、交叉验证方法 |
| `references/ima_sync.md` | 参考 | IMA 知识库配置、七篇报告文件映射、各报告更新检查清单、IMA 上传注意事项 |
| `scripts/check_updates.py` | 脚本 | Python脚本，自动检查追踪表中各指标的更新状态 |

**使用资源文件的原则：**
- 生成模板时，读取 `assets/tracker_template.md` 并输出给用户
- 指导数据获取时，先读取 `references/data_sources.md`，再回答用户问题
- 检查更新状态时，优先运行 `scripts/check_updates.py`；如运行失败，使用手动判断逻辑
- 执行"更新报告并同步到 IMA"功能时，读取 `references/ima_sync.md` 获取知识库配置和上传注意事项

## 常见问题处理

**用户：我没有时间维护完整的七层追踪表**
→ 提供"最低维护方案"：仅追踪第五层核心指标（GDP、CPI、PMI、社融、进出口），每季度更新一次。

**用户：追踪表太多数据要填，不知从何开始**
→ 建议先填第五层（经济体系）的6个核心指标：GDP增速、CPI、PPI、PMI、社会消费品零售总额、进出口总额。这6个指标覆盖大部分宏观判断需要。

**用户：某些数据找不到最新值**
→ 在追踪表中填写"待更新"，记录尝试获取的日期。部分数据（如基尼系数）官方已多年未发布，可用学术研究估算值替代并注明来源。

**用户：我想用Excel而不是Markdown**
→ 本技能默认提供Markdown格式（易于版本控制和AI处理）。如用户坚持使用Excel，可将Markdown表格复制到Excel中，或请用户说明需求，技能可指导格式转换。
